## Introduction  
FastAPI‑Users is a popular, lightweight authentication library built on top of **FastAPI** and **SQLAlchemy** (with optional support for **MongoDB/ODMantic**). It provides ready‑made routers for user registration, login, password reset, account verification, and OAuth2 integration, while exposing a clean abstraction layer (`BaseUserManager`) that lets maintainers plug in custom user models, storage backends, or authentication strategies.  

This explainer walks a maintainer (or sponsoring company) through the codebase in a structured, page‑by‑page fashion, enabling rapid onboarding, confident contribution, and clear communication of the project’s value to sponsors.
