## Overview  

FastAPI is a modern, high‑performance web framework for building APIs with Python 3.7+ based on Starlette for the web parts and Pydantic for data validation. Its main selling points are:  

* **Speed** – comparable to NodeJS and Go thanks to Starlette’s async core.  
* **Developer productivity** – automatic interactive API docs (Swagger UI, ReDoc) generated from type hints.  
* **Robustness** – data validation, serialization, and dependency injection built‑in.
