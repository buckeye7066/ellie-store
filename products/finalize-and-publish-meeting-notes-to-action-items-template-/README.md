## How to Use This Pack  

1. **Create a new page** in your Notion workspace (or open an existing database where you want the template).  
2. **Switch to “Full Page”** view if you are adding a database.  
3. **Copy the markdown block** for the template you want (including the triple back‑ticks).  
4. **Paste** the block into the new Notion page. Notion will automatically convert the markdown into a database/table with the correct properties.  
5. **Rename** the database if desired, adjust any property types (e.g., date, select, person), and start filling in your meeting data.  
6. **Duplicate** the template for each new meeting or reuse the same database with different views.
