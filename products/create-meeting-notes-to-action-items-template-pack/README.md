# Meeting Notes to Action Items Template Pack

This pack contains everything you need to turn raw meeting notes into clear, trackable action items without building anything from scratch.

## Files Included
- `Notion_Template.csv` – Importable CSV for a Notion table/action‑item database  
- `Word_Template.docx` – Microsoft Word template (copy the content into a new .docx file)  
- `Google_Docs_Template` – Ready‑to‑paste content for a Google Doc (use built‑in dropdowns)  
- `Guide.pdf` – Step‑by‑step PDF guide: “From Meeting Notes to Action Items”

## What’s Inside Each Template
Each template includes the same core sections:

1. **Meeting Metadata** – Date, time, facilitator, attendees, purpose.  
2. **Notes Area** – Structured prompts to capture decisions, open questions, and key points.  
3. **Action‑Item Table** – Columns: Item, Owner, Due Date, Status, Priority (1‑5), Notes.  
4. **Status Dropdowns** – Not Started, In Progress, Completed, Blocked.  
5. **Priority Scale** – 1 = Low, 2 = Low‑Medium, 3 = Medium, 4 = Medium‑High, 5 = High.  
6. **Example Data** – One filled‑out row to illustrate usage.

## How to Use
1. **Notion** – Open Notion, click **Import → CSV**, select `Notion_Template.csv`, choose “Create a new database”, and drag the template into your workspace.  
2. **Word** – Open Microsoft Word, create a new blank document, paste the content from `Word_Template.docx`, then save as `.docx`. Use the **Developer** tab to add dropdown content controls for the Status and Priority columns (instructions inside the file).  
3. **Google Docs** – Open a new Google Doc, paste the content from `Google_Docs_Template`. Use **Insert → Dropdown** to create the Status and Priority dropdowns (values pre‑listed).  
4. **Guide** – Open `Guide.pdf` (or print) and follow the workflow for best‑practice note‑taking and action‑item conversion.
