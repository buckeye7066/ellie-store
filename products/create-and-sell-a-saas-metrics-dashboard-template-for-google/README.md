## How to Recreate the Template  

1. **Create a new Google Sheet**  
   - Open Google Sheets → Blank spreadsheet.  

2. **Add three sheets**  
   - Rename the default sheet to `Data Input`.  
   - Click the **+** button twice to add two more sheets; rename them `Calculations` and `Dashboard`.  

3. **Paste the TSV data**  
   - For each sheet, select cell **A1**, then paste the corresponding TSV block (including the header row).  
   - After pasting, Google Sheets will automatically split the tab‑delimited text into columns.  

4. **Verify formulas**  
   - All formulas are preserved as plain text; they will become active formulas once pasted.  
   - If any formula shows as plain text (e.g., starts with an apostrophe), delete the leading apostrophe.  

5. **Optional: Protect calculation columns**  
   - To prevent accidental overwrites, protect the columns in `Calculations` and `Dashboard` that contain formulas (Data → Protect sheets and ranges).
