## 1. Project Overview  

FlexFactor is a pure‑Python library for **flexible factor analysis** that lets users specify arbitrary prior distributions, likelihoods, and variational families for latent factor models. Its main goals are:  

* **Modularity** – swap out inference algorithms (mean‑field VI, black‑box VI, MCMC) without touching model code.  
* **Extensibility** – users can plug in custom priors or likelihoods by subclassing `Prior` and `Likelihood`.  
* **Performance** – vectorized NumPy operations, optional JAX backend for GPU acceleration.
