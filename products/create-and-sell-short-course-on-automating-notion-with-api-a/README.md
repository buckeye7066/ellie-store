## Course Overview  

**Goal:** By the end of this course you will be able to read, create, update, and delete Notion data using the Notion API and Python, and you will have a reusable Notion workspace template plus automation scripts that you can run on any schedule.

**Target Learner:** Anyone who already knows basic Python (variables, loops, functions, `requests` library) and has a Notion account. No prior API experience required.

**Deliverables:**  

1. Four video lessons (≈12‑15 min each) – full narration scripts and slide outlines below.  
2. A downloadable Notion template (JSON export) that includes a **Projects** database, a **Tasks** database, and a **Metrics** page with linked views.  
3. Three Python scripts:  
   * `notion_read.py` – fetch data from Notion and export to CSV/JSON.  
   * `notion_write.py` – create/update pages and blocks.  
   * `notion_sync.py` – a scheduled sync that pulls external CSV data into Notion and pushes updates back.  
4. A `requirements.txt` file and a short setup guide (`.env` file example).  

**Access:** Hosted on Teachable; learners enroll, receive immediate access to Lesson 1, then one new lesson per day (drip). All downloadable assets are available in the course resources tab after enrollment.
