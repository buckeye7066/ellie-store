## 1. Project Overview  

FlexFactor is a **zero‑runtime CSS‑in‑JS library** that lets developers declare responsive flexbox layouts via a tiny API (`flex`, `gap`, `wrap`, `justify`, `align`, …) while keeping the generated CSS minimal and cache‑friendly.  

- **Stars:** ~12 k on GitHub  
- **License:** MIT  
- **Primary language:** TypeScript (strict mode)  
- **Build system:** Vite + Rollup (ESM & CJS outputs)  
- **Runtime footprint:** < 2 KB gzipped  

The library is **framework‑agnostic**; it ships with optional React hooks (`useFlexFactor`) and a vanilla‑JS facade. The state‑management explained below concerns the **internal CSS generation cache** and the **theme/context system** that powers the React hooks.
