# Naming and Brand Kit Starter – Updated Pathway

## Overview
This pathway guides you from idea to a validated brand name, tagline, and voice foundation in 5‑7 days. Each step includes worksheets, scoring scales, and deliverables you can copy into your own docs.

## Step 1 – Brand Core Definition (Day 1)
Goal: Clarify mission, vision, values, and target audience.
- Worksheet: Brand Core (fill-in)
  - Mission statement (max 160 characters)
  - Vision statement (max 160 characters)
  - Core values (pick 3‑5 from list: Innovation, Trustworthiness, Playfulness, Sustainability, Luxury, Accessibility, Expertise, Community)
  - Target audience persona (age, gender, occupation, pain point, desired outcome)
- Scale: Clarity (1‑5) – rate how clear each element feels after completion.

## Step 2 – Language Mining (Day 1‑2)
Goal: Gather words that resonate with your audience and brand.
- Exercise: Audience Language Map
  - List 10 words your audience uses to describe the problem.
  - List 10 words they use to describe the desired outcome.
  - List 10 industry‑specific terms.
  - List 5 emotion words you want them to feel.
- Output: Word Bank (CSV format). Example columns: Source, Word, Relevance (1‑5).

## Step 3 – Name Generation Techniques (Day 2‑3)
Goal: Produce a raw list of 50‑100 name candidates.
- Techniques (with templates):
  1. **Combinatory**: Core Value + Audience Adjective + Industry Keyword.
     - Template: `[Value][Adjective][Keyword]` (e.g., TrustySwiftBank).
  2. **Evocative**: Metaphor or imagery from Word Bank.
     - Template: `[Metaphor][Modifier]` (e.g., SummitPulse).
  3. **Invented**: Blend or twist of two words.
     - Template: `Blend(WordA, WordB)` (e.g., Finova = Finance + Nova).
  4. **Descriptive**: Direct statement of benefit.
     - Template: `[Benefit] + [Descriptor]` (e.g., QuickLedger).
- Worksheet: Name Generator (fill rows for each technique, aim for 20 per technique).
