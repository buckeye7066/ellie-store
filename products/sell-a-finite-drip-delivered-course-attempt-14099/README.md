## Lesson 1 – Getting Comfortable with the Excel Interface  

**Objective:** Navigate Excel confidently, understand the ribbon, and locate the Formula Bar.  

### 1.1 Workbook Anatomy  
- **Workbook** – the entire .xlsx file.  
- **Worksheet** – a single tab inside the workbook (default names: Sheet1, Sheet2…).  
- **Cell** – the intersection of a column (letter) and a row (number), e.g., B5.  

### 1.2 Key Areas of the Ribbon  
| Tab | Typical Groups | What You’ll Use Most |
|-----|----------------|----------------------|
| Home | Font, Alignment, Number, Styles, Cells, Editing | Formatting, copy/paste, clearing |
| Formulas | Function Library, Defined Names, Formula Auditing, Calculation | Inserting functions, tracing errors |
| View | Workbook Views, Show/Hide, Zoom, Window | Switching Normal/Page Layout, freezing panes |

### 1.3 The Formula Bar  
Located just below the ribbon, it shows the contents of the active cell. When you type `=`, Excel knows you’re entering a formula.  

### 1.4 Practice Exercise  
1. Open a new workbook.  
2. Click cell **A1** and type `Hello Excel`. Press **Enter**.  
3. Move to **B2** and type `123`. Press **Enter**.  
4. Observe the Formula Bar change as you select each cell.  

**Checkpoint:** You should see the text in A1 and the number in B2 reflected in the Formula Bar when each cell is selected.

## Lesson 2 – Basic Arithmetic Formulas  

**Objective:** Perform addition, subtraction, multiplication, and division using cell references.  

### 2.1 The Equal Sign (`=`)  
Every formula starts with `=`. Without it, Excel treats the entry as plain text.  

### 2.2 Arithmetic Operators  
| Operator | Meaning | Example |
|----------|---------|---------|
| `+` | Addition | `=A1+B1` |
| `-` | Subtraction | `=A1-B1` |
| `*` | Multiplication | `=A1*B1` |
| `/` | Division | `=A1/B1` |

### 2.3 Using Cell References  
Instead of typing numbers directly, refer to cells. This makes formulas dynamic.  

**Example:**  
- A1 contains `10`  
- B1 contains `5`  
- In C1, type `=A1+B1` → result `15`.
