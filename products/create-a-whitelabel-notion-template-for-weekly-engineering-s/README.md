## Template Structure

### Sprint Metrics Database
| Property | Type | Description |
|---|---|---|
| Sprint | Title | Name of the sprint (e.g., Sprint 23) |
| Start Date | Date | First day of the sprint |
| End Date | Date | Last day of the sprint |
| Planned Points | Number | Story points committed at sprint start |
| Completed Points | Number | Story points completed by sprint end |
| Velocity (%) | Formula | `round(prop("Completed Points") / prop("Planned Points") * 100)` |
| Retrospective Date | Date | Date the retrospective was held |

**Views**  
- **Table** (default)  
- **Timeline** (grouped by Start Date)  
- **Gallery** (displays Velocity as a progress bar)

### Retrospective Checklist
- [ ] **What went well?** – Add bullet points under this heading.  
- [ ] **What could be improved?** – Add bullet points under this heading.  
- [ ] **Action Items** – Link to items in the Action Items database.  
- [ ] **Team Mood** – Optional emoji scale (😠 😐 🙂 😄 😃).  
- [ ] **Next Sprint Goals** – List objectives for the upcoming sprint.

### Action Items Database
| Property | Type | Description |
|---|---|---|
| Item | Title | Short description of the action |
| Owner | Person | Team member responsible |
| Due Date | Date | Target completion date |
| Status | Select | To Do, In Progress, Done |
| Priority | Select | Low, Medium, High |
| Related Sprint | Relation | Link to a Sprint Metrics entry |
| Effort Estimate | Number | Estimated hours to complete |
| Actual Effort | Number | Actual hours spent (fill after work) |
| Completion Date | Date | Formula: `if(prop("Status") == "Done", prop("Due Date"), empty)` |
