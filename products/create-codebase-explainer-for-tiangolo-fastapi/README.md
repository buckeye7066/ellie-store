## 1. Project Overview
FastAPI is a modern, high‑performance web framework for building APIs with Python 3.7+ based on standard Python type hints. Its main goals are:
- **Speed:** comparable to NodeJS and Go, thanks to Starlette for the web parts and Pydantic for data handling.  
- **Developer productivity:** automatic interactive API docs (Swagger UI, ReDoc), dependency injection, and data validation with minimal code.  
- **Robustness:** built‑in support for async/await, WebSockets, background tasks, and security utilities.  

The repository (`tiangolo/fastapi`) is the canonical source used by maintainers and sponsors to produce releases, manage issues, and guide contributors. This explainer walks a new contributor through the codebase so they can confidently triage issues, submit pull requests, and improve documentation.
