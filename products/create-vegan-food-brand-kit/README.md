## 1. Naming & Tagline Workshop (PDF Pages 2‑5)

### 1.1 Name Generation Framework
| Step | Action | Output |
|------|--------|--------|
| 1 | List core values (e.g., compassion, sustainability, flavor) | 5‑7 words |
| 2 | Identify ingredient heroes (e.g., jackfruit, oat, algae) | 3‑5 words |
| 3 | Combine values + heroes using formulas: <br>• **[Value] + [Hero]** (e.g., *PureJack*) <br>• **[Hero] + [Action Verb]** (e.g., *OatFuel*) <br>• **[Adjective] + [Plant]** (e.g., *VerdantBean*) | 10‑15 candidate names |
| 4 | Screen for domain availability (.com, .food) and trademark clearance (USPTO TESS) | Shortlist 3‑5 names |
| 5 | Vote with team using 1‑5 scale on: Memorability, Relevance, Pronounceability, Legal safety | Final name |

### 1.2 Tagline Formulas
- **Benefit‑Driven**: “*[Verb] your [Benefit]*” (e.g., *Fuel your vitality*)
- **Mission‑Driven**: “*[Adjective] food for a [Impact]*” (e.g., *Kind food for a kinder planet*)
- **Playful**: “*[Ingredient] meets [Emotion]*” (e.g., *Jackfruit joy*)

Select one formula, insert the chosen name, and test with a 5‑question survey (Likert 1‑5) on clarity, appeal, and brand fit.
