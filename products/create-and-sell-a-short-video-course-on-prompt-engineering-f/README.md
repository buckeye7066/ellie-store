## Course Overview  
Learn how to design, test, and optimize prompts for large language models (LLMs) to improve code generation, debugging, and developer productivity. By the end of this course you will be able to craft effective prompts, evaluate their quality, and integrate prompt engineering into your development workflow.  

### Who Should Take This Course  
- Software developers, data engineers, or dev‑ops engineers who want to harness LLMs for coding tasks.  
- No prior experience with LLMs required; basic Python familiarity assumed.  

### Prerequisites  
- Python 3.8+ installed.  
- An account with an LLM provider (OpenAI, Azure OpenAI, or HuggingFace Inference API).  
- Basic knowledge of REST APIs and JSON.  

### Learning Outcomes  
1. Explain what prompt engineering is and why it matters for developers.  
2. Identify core components of a good prompt (instruction, context, examples, format).  
3. Apply common prompt design patterns (zero‑shot, few‑shot, chain‑of‑thought, role‑playing).  
4. Use advanced techniques such as self‑consistency, retrieval‑augmented generation, and prompt chaining.  
5. Evaluate prompt quality with quantitative metrics (BLEU, ROUGE, Exact Match, human‑in‑the‑loop).  
6. Build a small developer‑assistant project that generates boilerplate code from natural‑language specifications.
