## Overview  
This product provides a **cleaned, versioned, and citable** extract of the USDA FoodData Central (FDC) Branded Foods dataset released in 2023. The original data spans dozens of API endpoints and PDF documentation; this deliverable consolidates it into a single CSV (and optional JSON) file with:

* Uniform column names and data types.  
* Missing‑value handling documented in the dictionary.  
* A `source_url` column that records the exact API endpoint used to retrieve each row.  
* A machine‑readable data dictionary (CSV) and a human‑readable markdown version.  
* A permissive CC0 license allowing unrestricted commercial and non‑commercial use.  

The dataset is intended for analysts, small nonprofits, or data‑marketplace sellers who need a trustworthy reference without spending time scraping and normalising the raw USDA feeds.
