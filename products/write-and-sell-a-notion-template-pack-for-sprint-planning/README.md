# Sprint Planning Notion Template Pack

## README

This product is a ready‑to‑use Notion template pack for agile sprint planning.  
Inside the download you will find the following files:

| File | Description |
|------|-------------|
| `Sprints.csv` | CSV export of the **Sprints** database (properties: Sprint Name, Start Date, End Date, Goal, Status, Velocity). |
| `Backlog.csv` | CSV export of the **Backlog** database (properties: ID, Title, Description, Priority, Effort, Sprint, Status, Tags). |
| `Tasks.csv` | CSV export of the **Tasks** database (properties: ID, Title, Description, Assignee, Due Date, Effort, Sprint, Status, Blocked By). |
| `Import-Instructions.md` | Step‑by‑step guide to import the CSVs into Notion and turn them into databases with the recommended views (Sprint Planning Board, Backlog List, Daily Standup Table, Retrospective Board, Burndown Chart). |
| `Sample-Data.md` | Example rows showing how to fill each database for a two‑week sprint. |

All files are plain text (CSV/Markdown) and can be imported directly into any Notion workspace. No external tools or paid plugins are required.
