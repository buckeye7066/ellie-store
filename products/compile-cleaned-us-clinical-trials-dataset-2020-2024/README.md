## Overview  
This product provides a cleaned, versioned reference dataset derived from the public ClinicalTrials.gov bulk export for all U.S.-located studies with a start date between 1 Jan 2020 and 31 Dec 2024. The dataset contains approximately 150 000 rows, each representing a unique clinical trial record. All fields have been standardized, missing values handled per documented rules, and per‑row source citations added to enable traceability back to the original NCT identifier.  

The dataset is supplied in both CSV and JSON Lines formats, accompanied by a detailed data dictionary, a machine‑readable license, and a short reproducibility script.
