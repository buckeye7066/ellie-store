# Meeting Notes to Action Items Template for Remote Teams  

## How to Use This Template  
1. **Duplicate the template** – Open the Notion page, click `•••` → `Duplicate` to create your own workspace copy.  
2. **Fill the Meeting Agenda** – Add a new row for each meeting, populate date, attendees, objective, agenda items, time allocations, and decisions.  
3. **Link Action Items** – In the Action Tracker, use the *Related Meeting* relation to pull the meeting where the action originated.  
4. **Update Status** – Change the *Status* select as work progresses; overdue items will highlight automatically.  
5. **Review Weekly** – Use the Calendar or Board views to see upcoming deadlines and bottlenecks.
