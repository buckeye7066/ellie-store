**Slide 2 – Why Prompt Engineering?**  
- LLMs are powerful but deterministic only via input.  
- Legal tasks demand precision, citation, and jurisdiction‑specific language.  
- Poor prompts → hallucinations, irrelevant output, wasted time.  

**Slide 3 – The Prompt Anatomy Framework**  
| Element | Purpose | Example (Legal) |
|---------|---------|-----------------|
| Role | Sets the model’s perspective | “You are a senior associate at a corporate law firm.” |
| Task | States what you want done | “Draft a confidentiality clause for a SaaS agreement.” |
| Context | Supplies background facts | “The parties are domiciled in California; data includes user‑generated content.” |
| Constraints | Limits length, tone, format | “Maximum 150 words, plain English, no legalese.” |
| Format | Specifies output structure | “Return as a single paragraph, then a bullet list of defined terms.” |

**Slide 4 – Common Pitfalls & Fixes**  
- **Vague Role** → Add explicit title & seniority.  
- **Missing Constraints** → Impose word/jurisdiction limits.  
- **Conflicting Instructions** → Prioritize; use “If … then …” logic.  
- **Over‑loading** → Split into sub‑prompts (chain).
