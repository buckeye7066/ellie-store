# Cleaned Historical Newspaper Headlines (1900‑1920) Dataset & Processing Script

## Overview
This product delivers a ready‑to‑use CSV file containing cleaned, validated historical newspaper headlines from 1900‑1920, together with a reusable Python script that reproduces the cleaning pipeline from the raw public‑domain source (Chronicling America). Researchers and journalists can run the script to refresh the data or adapt it to other date ranges.

## Dataset Description
- **File name:** `headlines_1900-1920.csv`
- **Columns:**
  - `date` (YYYY‑MM‑DD) – publication date of the issue.
  - `newspaper` – title of the newspaper as recorded in the source.
  - `headline` – article headline, stripped of HTML tags and normalized whitespace.
  - `location` – city and state (or city, country for non‑US papers) where the newspaper was published.
  - `url` – direct link to the scanned page on the Chronicling America site.
- **Row count:** ~112,000 headlines (exact count depends on the snapshot date of the API).
- **Format:** UTF‑8 encoded CSV, comma‑separated, with quoting only when a field contains a comma or double‑quote.
- **License:** Public domain (source material is in the public domain; script released under MIT License).

## Data Sources
- **Primary source:** Chronicling America API (https://chroniclingamerica.loc.gov/search/pages/results/)
  - Provides JSON metadata for digitized newspaper pages.
  - All newspapers included are from 1900‑01‑01 to 1920‑12‑31 and are marked as public domain.
- **Supplemental source:** Newspaper title‑and‑location lookup CSV supplied by the Library of Congress (https://chroniclingamerica.loc.gov/newspapers/), used to fill missing location data.
