## Part 1: Name Generation Exercises  

### 1.1 Warm‑Up: Free Association (5 min)  

| Prompt | Instructions | Output (fill in the table) |
|--------|--------------|----------------------------|
| Core product/service | Write the primary function in one sentence. |  |
| Target user | Describe the ideal customer in 2‑3 words (e.g., “busy parents”). |  |
| Emotion you want to evoke | Choose one feeling (trust, excitement, curiosity). |  |
| Competitor names you dislike | List 3 names and why they feel off. |  |
| Words you love | Jot down 5‑10 words that feel “right” for your brand. |  |

*After the timer, highlight any words that appear in two or more rows – these are seed concepts.*  

### 1.2 Morphological Mix‑And‑Match (10 min)  

1. **Create three columns** in a blank sheet: **Prefix**, **Root**, **Suffix**.  
2. **Fill each column** with at least 8 entries (see examples below).  
3. **Combine** one entry from each column to form a name. Aim for 30‑40 combos.
