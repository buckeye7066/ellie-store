## Project Overview
SvelteKit is the official application framework for Svelte, providing file‑based routing, server‑side rendering (SSR), static site generation (SSG), and API endpoints in a unified, convention‑over‑configuration manner. The codebase lives in the `sveltejs/kit` monorepo on GitHub and is maintained by the Svelte core team with sponsorship visible in `FUNDING.yml`.
